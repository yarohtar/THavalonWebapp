Balin can only be in 9-player games, where the host may add them like any other role. Like [[Gareth]], Balin plays on top of the Evil players the host chooses: the usual 9-player game is 3 Evil, Balin and 5 Good.

{% else %} {% call p(True) %}{% if counts %}Balin can be dealt {{ counts_phrase(counts) }}, where the host may add them like any other role.{% else %}Balin is never dealt.{% endif %} Balin plays on top of the Evil players the host chooses, in place of an Evil player (or of a Good player, if there would be fewer than 2 Evil players otherwise).{% endcall %} {% endif %} {% if ruleset['Balin.or_gareth'] %}

When [[Gareth]] could be dealt too, only one of Balin and Gareth is in the game, chosen at random. Otherwise, a selected Balin is always dealt.

{% else %} {% call p(True) %}Balin and [[Gareth]] can both be in the game: Gareth then takes an Evil player's place and Balin a Good player's.{% endcall %} {% endif %}

Winning

{% if ruleset['Balin.must_fail'] %}

Balin is Good, but wins only if Good wins and Balin has played at least one [[Fail]] during the game.

  • The Quest Balin fails on doesn't have to fail: the Fail just has to be played.
  • A Fail that a [[Strong Inquisition]] removes still counts as played.
  • If Evil wins, Balin loses with the rest of Good.
{% else %} {% call p(True) %}Balin is Good and wins whenever Good wins. Balin may play [[Fail]], like any Good player.{% endcall %} {% endif %}

Proposals

For the number of [[Proposals]] and the [[Inquisition]], Balin counts as an Evil player, like Gareth. With 3 Evil and Balin, each round has 5 proposals, with Strong and Weak Inquisition: the same as with Gareth, so the count doesn't tell which of them is in the game.
